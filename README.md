# 연장결제기일 간이 계산기

물품인도일과 보험증권상 결제기간을 입력하면 **결제기일**과 **연장결제기일**을 계산하는 정적 웹 페이지입니다.
외부 CDN·웹폰트·라이브러리를 사용하지 않아 폐쇄망에서도 그대로 동작합니다.

## 파일 구조

```
.
├── index.html        # 마크업
├── css/
│   └── style.css     # 스타일 (커스텀 달력 · 반응형 · 인쇄용 포함)
├── js/
│   ├── holidays.js   # 공휴일 데이터 (2020~2027)
│   └── app.js        # 계산 로직 · 커스텀 달력 · 결과 이미지 생성
└── README.md
```

`holidays.js`는 데이터만, `app.js`는 로직만 담당합니다. 매년 말 공휴일을 갱신할 때는
`app.js`를 건드리지 않고 `holidays.js`만 수정하면 됩니다. `index.html`에서
`holidays.js`가 `app.js`보다 먼저 로드되어야 합니다.

## 계산 규칙 (역일/달력일 기준 + 종료일 휴일 보정)

| 순서 | 항목 | 규칙 |
| --- | --- | --- |
| ① | 기산일 | 물품인도일이 속한 달의 **다음 달 1일** |
| ② | 결제기일 | 기산일을 1일째로 하여 결제기간만큼 **역일(달력일)**을 센 날 → 그 날이 휴일이면 **다음 영업일로 이월** |
| ③ | 연장결제기일 | 결제기일 + 2개월 (같은 날짜, 없으면 말일) → 그 날이 휴일이면 **다음 영업일로 이월** |

기간을 세는 동안에는 휴일을 건너뛰지 않고 달력일 그대로 센다. **다 센 뒤 "끝나는 날"이 휴일일 때만**
다음 영업일로 옮긴다. (②의 결제기일, ③의 연장결제기일 각각에 이 보정을 적용)

영업일 = 토·일요일과 관공서 공휴일을 제외한 날

### 검증 예시

| 물품인도일 | 결제기간 | ① 기산일 | ② 결제기일 | ③ 연장결제기일 |
| --- | --- | --- | --- | --- |
| 2026-08-20 | 31일 | 2026-09-01 | 2026-10-01 | 2026-12-01 |
| 2026-07-01 | 55일 | 2026-08-01 | 2026-09-28 | 2026-11-30 |
| 2026-09-15 | 30일 | 2026-10-01 | 2026-10-30 | 2026-12-30 |
| 2026-01-15 | 180일 | 2026-02-01 | 2026-07-30 | 2026-09-30 |

(위 예시는 마침 휴일 보정이 필요 없는 날짜들입니다. 결제기일 또는 연장결제기일이 휴일에 걸리면 그
날짜만 다음 영업일로 옮겨집니다.)

## 공휴일 목록

`js/holidays.js`의 `HOLIDAY_LIST` 배열에 있습니다. **2020-01-01 ~ 2027-12-31** 구간을 대체공휴일까지 반영했습니다.
2020~2024년은 이미 확정된 과거 공휴일이고, 2025~2027년은 관공서 공휴일 규정 및 월력요항 기준입니다.

- 임시공휴일이 새로 지정되면 `js/holidays.js`에 `'YYYY-MM-DD'` 형식으로 추가하세요. (`js/app.js`는 건드리지 않습니다)
- 5월 1일(근로자의 날)은 금융기관 휴무일이라 포함했습니다. 제외하려면 해당 날짜만 지우면 됩니다.
- 목록을 늘렸다면 `js/holidays.js`의 `COVERAGE` 값도 함께 수정하세요. 계산에 사용된 날짜(물품인도일
  또는 연장결제기일)가 이 범위를 벗어나면, 공휴일이 반영되지 않고 주말만 제외해 계산되었다는 안내
  문구가 결과 화면에 자동으로 표시됩니다.

매년 말 우주항공청 월력요항이 공개되면 다음 해 목록을 추가하시면 됩니다.

## 입력 규격

- **물품인도일** : 커스텀 달력에서 선택 (연/월 드롭다운 · 이전/다음 달 · 오늘 · 취소 / 확인)
- **결제기간** : 1 ~ 180 (최대 3자리)
  - `모름` 선택 시 31일 고정 + 읽기 전용, 안내 문구 표시
  - `일수 입력` 선택 시 필드를 비우고 포커스 이동, 안내 문구 숨김

## 하단 버튼

| 환경 | 버튼 | 동작 |
| --- | --- | --- |
| PC (680px 초과) | 인쇄하기 | `window.print()` — 유의사항을 자동으로 펼쳐 함께 인쇄 |
| 모바일 (680px 이하) | 캡쳐하기 | 결과를 PNG로 생성 후 공유 시트 또는 다운로드 |

> 공유 시트(`navigator.share`)는 HTTPS 또는 localhost에서만 동작합니다.
> HTTP 환경에서는 자동으로 파일 다운로드로 전환됩니다.

## 설정 변경

`js/app.js` 상단 상수만 수정하면 됩니다.

```js
var DEFAULT_DAYS = 31;         // '모름' 선택 시 기본 일수
var MIN_DAYS     = 1;
var MAX_DAYS     = 180;
var GRACE_MONTHS = 2;          // 결제기일 이후 연장 개월 수
```

> 결제기간은 항상 역일(달력일) 기준으로 세며, 그렇게 정해진 결제기일·연장결제기일이 휴일이면
> 각각 다음 영업일로 이월됩니다. (별도 설정 스위치 없음)
