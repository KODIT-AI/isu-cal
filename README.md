# 이행지체 기준일 간이 계산기

물품인도일과 보험증권상 결제기간을 입력하면 **결제기일**과 **이행지체 기준일**을 계산하는 정적 웹 페이지입니다.
외부 CDN·웹폰트·라이브러리를 사용하지 않아 폐쇄망에서도 그대로 동작합니다.

## 파일 구조

```
.
├── index.html        # 마크업
├── css/
│   └── style.css     # 스타일 (반응형 · 인쇄용 스타일 포함)
├── js/
│   └── app.js        # 계산 로직 · 결과 이미지 생성
└── README.md
```

## 계산 규칙

| 순서  | 항목       | 규칙                                         |
| --- | -------- | ------------------------------------------ |
| ①   | 결제기간 기산일 | 물품인도일이 속한 달의 **다음 달 1일**                   |
| ②   | 결제기일     | 기산일을 1일째로 하여 결제기간만큼 센 날 (기산일 + 결제기간 − 1일)  |
| ③   | 이행지체 기준일 | 결제기일의 **2개월 뒤 같은 날짜** (그 날짜가 없으면 해당 월의 말일) |

### 검증 예시

| 물품인도일      | 결제기간 | ① 기산일      | ② 결제기일     | ③ 이행지체 기준일         |
| ---------- | ---- | ---------- | ---------- | ------------------ |
| 2026-08-20 | 31일  | 2026-09-01 | 2026-10-01 | 2026-12-01         |
| 2026-08-01 | 31일  | 2026-09-01 | 2026-10-01 | 2026-12-01         |
| 2026-07-01 | 55일  | 2026-08-01 | 2026-09-24 | 2026-11-24         |
| 2026-10-05 | 180일 | 2026-11-01 | 2027-04-29 | 2027-06-29         |
| 2026-11-10 | 31일  | 2026-12-01 | 2026-12-31 | 2027-02-28 (말일 보정) |

물품인도일이 그 달의 며칠이든 기산일은 항상 다음 달 1일이므로, 같은 달 안에서는 결과가 동일합니다.

## 입력 규격

- **물품인도일** : 날짜 선택 (브라우저 기본 캘린더)
- **결제기간** : 30 ~ 180 (최대 3자리)
  - `모름` 선택 시 31일로 고정하고 읽기 전용 처리 (다음 달 월말결제 기준)
  - `일수 입력` 선택 시 필드를 비우고 포커스 이동

## 하단 버튼

| 환경             | 버튼   | 동작                                    |
| -------------- | ---- | ------------------------------------- |
| PC (680px 초과)  | 인쇄하기 | `window.print()` — 입력 영역을 제외하고 결과만 인쇄 |
| 모바일 (680px 이하) | 캡쳐하기 | 결과를 PNG로 생성 후 공유 시트 또는 다운로드           |

> 캡쳐의 공유 시트(`navigator.share`)는 HTTPS 또는 localhost에서만 동작합니다.
> HTTP 환경에서는 자동으로 파일 다운로드로 전환됩니다.

## 설정 변경

`js/app.js` 상단 상수만 수정하면 됩니다.

```js
var DEFAULT_DAYS = 31;   // '모름' 선택 시 기본 일수
var MIN_DAYS     = 30;   // 최소 입력값
var MAX_DAYS     = 180;  // 최대 입력값
var GRACE_MONTHS = 2;    // 결제기일 이후 연장 결제 기간(개월)
```

말일 보정 방식(예: 2월 31일 → 2월 말일 대신 3월 1일)을 바꾸려면 `js/app.js`의 `addMonths()` 함수를 수정하세요.
